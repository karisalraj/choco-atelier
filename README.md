## ✨ About the Project

**Choco Atelier** is a premium full-stack chocolate e-commerce platform built with **React** and **FastAPI**.

The application provides a complete chocolate shopping experience with product browsing, cart management, checkout, customer order placement, and an admin order management system.

---

## 🍫 Features

- Cinematic chocolate experience
- Product browsing
- Shopping cart
- Checkout
- Customer order placement
- Order confirmation
- Order status management
- Admin authentication
- Admin order dashboard
